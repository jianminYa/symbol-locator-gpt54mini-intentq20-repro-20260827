## 改动清单(7 个文件)

1. **`explorers/base.py`**
   `ExplorerResult` 加 `extras: dict | None = None`,承载 per-run token 统计,不破坏现有 explorer。

2. **`symbol_locator/scorer.py`**
   - 模块级 `_USAGE = {"prompt_tokens":0, "completion_tokens":0, "calls":0}` + `pop_usage()`
   - `score_batch` 里每次 `litellm.completion` 后从 `resp.usage` 累加
   - 每次 score_batch 结束**同步写** `SYMBOL_LOCATOR_USAGE_OUT` sidecar(atomic rename)

3. **`symbol_locator/install.py`**
   `_register_scorer_usage_dump()` 改成 no-op —— atexit 在 LocAgent 的 fork 子进程里不可靠(os._exit 路径),且在没累加的 fork child 里 `pop_usage()` 会把 sidecar 清零。同步写代替。

4. **`third_party/LocAgent/auto_search_main.py`**
   把 `loc_res['usage'] = {...}` 移到 `append_to_jsonl` 之前,保证 `loc_outputs.jsonl` 带 usage。

5. **`explorers/parsing.py`**
   `parse_locagent_jsonl` 读 `rec['usage']` → 塞进 `ExplorerResult.extras.agent_prompt_tokens/agent_completion_tokens`。

6. **`explorers/locagent_explorer.py`**
   `explore()` 前设 `env["SYMBOL_LOCATOR_USAGE_OUT"] = <output_folder>/scorer_usage.json`;parse 后把 sidecar 折进每个 `ExplorerResult.extras`,加 `scorer_prompt_tokens/scorer_completion_tokens/scorer_calls`。A 面 sidecar 不存在 → 全 0。

7. **`eval_runner.py`**
   `_extras_by_iid` 侧信道:`_agentic_method` 里 `explore()` 后写入;`_record_result` 里 pop 出来 setdefault 补 0(A/B 统一 schema),再算 `agent_total_tokens / scorer_total_tokens / total_tokens`,并入 metrics 落盘。

## 踩过的坑

**坑 1:A 面 metrics 缺 scorer_\* 字段** —— A 面不建 sidecar,parsing 里没塞就没有,不是 0 是"根本不存在"。**修**:`_record_result` 里 `extras.setdefault("scorer_prompt_tokens", 0)`。

**坑 2:B 面 scorer_\* 一直是 0**
- 日志明明有 `[scorer] parsed 5/5 scores from LLM` × 8 次
- Sidecar 文件 `{"prompt_tokens":0, "completion_tokens":0, "calls":0}`
- **根因**:LocAgent `mp.get_context('fork')` 起 auto_search 子进程,`_USAGE` 累加在 fork 孙进程 pid=3321387;atexit 从没在这个 pid 触发(可能是 os._exit),或者在另一个没累加的 fork 兄弟里触发 → 用 pop 出来的 0 把 sidecar 覆盖了。
- **修**:scorer 里 `_flush_sidecar()` 每次 score_batch 结束同步写(atomic tmp+rename);install.py 里 atexit 全删。
